# Emma 3D English Tutor (스마트폰 3D 영어 회화 튜터)

스마트폰 브라우저에서 바로 실행되고, 홈 화면에 추가(PWA)하여 단독 앱처럼 쓸 수 있는 3D 애니메이션 캐릭터 영어 회화 & 롤플레잉 앱입니다.

---

## 📱 스마트폰에서 실행하는 방법 (가장 간단한 방법)

### 1단계: PC에서 서버 실행
- `english-vrm-tutor` 폴더에 있는 **`run_mobile_server.bat`** 파일을 더블 클릭하여 실행합니다.
- 검은 터미널 창에 다음과 같이 접속 주소가 나타납니다:
  ```text
  * PC 접속 주소       : http://localhost:8080
  * 스마트폰 접속 주소 : http://192.168.x.x:8080
  ```

### 2단계: 스마트폰 브라우저로 접속
1. 스마트폰을 PC와 **동일한 Wi-Fi(공유기)**에 연결합니다.
2. 스마트폰 브라우저(Chrome, Safari 등)를 열고 터미널에 뜬 **`스마트폰 접속 주소`**를 입력합니다.

### 3단계: '홈 화면에 추가' (스마트폰 전용 앱으로 설치)
- **아이폰 (Safari)**: 화면 하단 **공유 버튼(네모+화살표)** 누른 뒤 **[홈 화면에 추가]** 터치
- **안드로이드 (Chrome)**: 우측 상단 **메뉴(점 3개)** 누른 뒤 **[홈 화면에 추가]** 또는 **[앱 설치]** 터치
- 이제 스마트폰 바탕화면에 **Emma 아이콘**이 생기며, 인터넷 주소창 없는 깔끔한 전체화면 앱으로 실행됩니다!

## 🌟 주요 기능 및 사용법

### 1. 2단계 영어 몰입 학습 커리큘럼
- **Stage 1: 핵심 문장 마스터 (Sentence 1/3 ~ 3/3)**
  - **Listen**: 3D 캐릭터 Emma가 자연스러운 원어민 발음과 립싱크로 문장을 읽어줍니다.
  - **마이크 버튼**: 소리 내어 따라 말하면 음성을 인식하고 실시간 피드백을 제공합니다.
  - **Next**: 다음 문장으로 넘어가며, 3문장을 모두 마치면 자동으로 Stage 2 롤플레잉으로 이동합니다.
- **Stage 2: 실시간 롤플레잉 회화**
  - 오늘의 핵심 표현을 활용해 특정 상황(카페, 레스토랑, 공항, 일상 대화)의 주인공이 되어 Emma와 음성으로 티키타카 회화를 나눕니다.
  - **Goal 버튼**: 현재 롤플레잉의 미션 목표를 언제든 확인할 수 있습니다.

### 2. 살아있는 3D 애니메이션 캐릭터
- 음성에 반응하여 입을 자연스럽게 뻐끔거리는 실시간 립싱크(`aa`, `ih`, `ou`, `ee`, `oh`)
- 자연스러운 호흡(Breathing), 고개 끄덕임, 주기적인 눈 깜빡임(Blink)

### 3. 나만의 3D 캐릭터(.vrm) 교체
- 상단 오른쪽 ⚙️ **설정** 버튼 -> **Custom 3D Avatar**에서 스마트폰에 있는 `.vrm` 파일(VRoid 등)을 선택하면 즉시 나만의 캐릭터로 교체됩니다.

### 4. Gemini API 키 등록 (무제한 롤플레잉)
- 상단 ⚙️ **설정** 버튼 -> Google AI Studio에서 발급받은 무료 **Gemini API Key**를 입력해 저장하면 최신 AI 모델(Gemini Flash)이 대화 맥락을 정확하게 파악하고 반응합니다.
- (키를 입력하지 않아도 기본 음성 연습 및 립싱크 모드는 정상 작동합니다.)
