# AI 원페이지 파워포인트 슬라이드 생성기 (AI PPT Generator)

보고서, 기획안, 전략 내용 등의 한국어 텍스트를 입력하면, Google Gemini AI가 핵심 내용을 파악하여 **단 1장의 비즈니스 파워포인트(.pptx) 슬라이드**로 자동 구조화 및 생성해 주는 프로그램입니다.

---

## 🌟 주요 기능 및 규격

1. **2가지 슬라이드 레이아웃 선택**
   - **1) 📊 표(Table) 형식**: 프러시안 블루 헤더와 깔끔한 검은색 테두리의 데이터 표 구성 (헤더·본문 14pt 고정)
   - **2) 🖼️ 내용 + 그림 형식**: 슬라이드 좌측(50%)에 핵심 요약 내용(소제목 15pt, 본문 13pt)을 배치하고, 우측(50%)은 이미지를 자유롭게 넣을 수 있는 점선 가이드 영역 제공
2. **비즈니스 디자인 규격 준수 (16:9 와이드)**
   - 메인 제목 (24pt 볼드, 왼쪽 맞춤)
   - 제목 아래 **■ 핵심 1줄 요약문** (16pt 볼드, 리드문/결론)
   - 제목과 본문 사이의 불필요한 분리선 제거로 깔끔한 여백 확보
   - 내용 입력창은 빈 칸으로 제공되어 삭제 번거로움 없이 즉시 붙여넣기 가능

---

## 🚀 실행 방법

### 방법 1: 크롬(Chrome) 브라우저에서 바로 실행 (추천)
별도의 파이썬 설치나 서버 구동 없이, 브라우저 자체(PptxGenJS)에서 즉시 PPTX 파일을 생성하고 다운로드합니다.

- `run_in_chrome.bat` 파일을 더블클릭하거나,
- `index.html` 파일을 크롬 브라우저로 열기만 하면 즉시 실행됩니다.
- (GitHub Pages로 설정 시 모바일이나 다른 PC에서도 URL만으로 바로 사용 가능)

### 방법 2: 파이썬 로컬 서버 방식
- `run_ppt.bat` 파일을 더블클릭하거나,
- 터미널에서 `ppt` (또는 `python ppt_server.py`) 입력
- 자동으로 크롬 브라우저가 열리며 `http://localhost:8000`으로 접속됩니다.

---

## 📁 파일 구성
- `index.html`: 크롬 브라우저 독립 실행형 웹 애플리케이션 (PptxGenJS + Gemini API 내장)
- `run_in_chrome.bat`: 크롬 브라우저로 `index.html`을 즉시 열어주는 실행 스크립트
- `ppt_server.py`: 파이썬 기반 로컬 웹 서버 및 PPTX 생성기
- `run_ppt.bat`: 파이썬 서버 실행 및 크롬 브라우저 자동 오픈 스크립트
- `template.pptx`: 기본 파워포인트 양식 템플릿
