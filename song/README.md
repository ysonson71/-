# SingToScore (마이크 음성 악보 변환기)

크롬 브라우저에서 마이크를 켜고 노래를 부르면 실시간으로 음정을 분석하고, 메트로놈 박자에 맞춰 정제된 5선지 악보로 자동 변환해주는 웹 애플리케이션입니다.

## 주요 기능
- **Web Audio API & MPM 피치 감지**: McLeod Pitch Method 알고리즘을 통한 고정밀 단음 보컬 주파수 인식 및 노이즈 게이트
- **정밀 메트로놈 & 카운트다운**: 4박자 준비 카운트다운 및 템포(BPM) 조절
- **4/4 박자 양자화(Quantization)**: 부른 음을 16분음표 그리드에 스냅하여 온음표/2분/4분/8분/16분음표 및 쉼표로 자동 정렬
- **5선지 악보 렌더링**: VexFlow 4 기반 깔끔한 악보 표시
- **악보 재생 (Synthesizer)**: 내장 웹 오디오 신디사이저로 생성된 악보 소리 미리듣기
- **내보내기 기능**:
  - 표준 MIDI (`.mid`) 파일 다운로드
  - 악보 이미지 (`.png`) 저장
  - 인쇄 및 PDF 저장

## 실행 방법
1. `run_in_chrome.bat`을 더블 클릭하여 실행합니다.
2. 브라우저(`http://localhost:8088`)가 열리면 마이크 권한을 허용합니다.
3. **`녹음 시작`**을 누르고 4박자 카운트다운 후 메트로놈에 맞춰 노래를 부릅니다.
4. 노래가 끝나면 **`녹음 종료 및 악보 생성`**을 누릅니다.
5. (마이크 없이 바로 테스트하려면 상단의 **`✨ 샘플 곡 로드 (작은 별)`**을 클릭하세요)
